# Osteo Manager

Application de bureau de gestion de cabinet d'ostéopathie : fiches patients, séances, factures PDF envoyées par mail, encaissements, dépenses et comptabilité BNC (2035).

Les données restent en local et sont chiffrées.

- Spécification : [docs/SPEC.md](docs/SPEC.md)
- Suivi : GitHub Issues + Projects

Stack : Tauri 2 · React · TypeScript · SQLite (SQLCipher)
